# CadFaster QuickStep — Free STEP File Viewer

**CadFaster|QuickStep** by CadFaster, Inc. is a high-performance 3D **STEP viewer** for Windows, built to streamline design reviews and improve collaboration across engineering and manufacturing teams.

The installer is included in this repository: [`files/CadFaster_QuickStep_2010_R1_Setup.exe`](./files/CadFaster_QuickStep_2010_R1_Setup.exe) (version 2010 R1).

## Key Features

- Fast opening of large STEP assemblies
- Smooth navigation: pan, zoom, rotate
- Section views and exploded views
- Precise measurements
- Part property review
- Comments and markups for design review feedback

## Installation

1. Download or clone this repository.
2. Run `files/CadFaster_QuickStep_2010_R1_Setup.exe` and follow the setup wizard.
3. Launch QuickStep and open your `.step` / `.stp` files.

If you cannot install software or just need a quick look at a STEP file, these free online viewers work directly in the browser:

1. [MeshMarkup STEP Viewer](https://www.meshmarkup.com/viewer/step)
2. [3DViewer.net](https://3dviewer.net/)
3. [ImageToSTL — View STP Online](https://imagetostl.com/view-stp-online)

## Alternatives: Desktop Viewers

### eDrawings Viewer (SOLIDWORKS)

**eDrawings Viewer** from the SOLIDWORKS developers opens and views STEP files as well as eDrawings (`.eprt`, `.easm`, `.edrw`) and native SOLIDWORKS files. The viewer edition is **free to download and use**.

- Download page: <https://www.edrawingsviewer.com/download-edrawings>

### DWG FastView

**DWG FastView** is a free CAD viewer that supports **STEP, DWG, STL, X_T, X_B** files, as well as **`.sldprt`** and **`.sldasm`** (SOLIDWORKS part and assembly files). Available for Windows, web, iOS, and Android.

- Download page: <https://ru.dwgfastview.com/activity/promotion-step/stp-viewer/>
- License: **Free**
